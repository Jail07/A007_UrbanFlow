# Computer Vision Comparison: UrbanFlow

Этот раздел содержит результаты сравнительного анализа двух версий систем компьютерного зрения для мониторинга городского трафика.

## 📝 Описание проекта

Проект **UrbanFlow** направлен на анализ транспортных потоков в реальном времени. В папке `src/test` представлены две итерации алгоритмов детекции и трекинга объектов.

*   **Версия 1 (`computer_vision_test.py`)**: Базовая детекция на базе YOLOv3.
*   **Версия 2 (`computer_vision_test_v2.py`)**: Продвинутая система на базе YOLOv8 с использованием трекера DeepSort.

## 🚀 Как запустить

### Предварительные требования
Убедитесь, что установлены необходимые зависимости:
```bash
pip install ultralytics deep_sort_realtime opencv-python numpy
```

### Запуск скриптов
Из корневой директории проекта:
```bash
# Запуск v1 (YOLOv3)
python -m src.test.computer_vision_test

# Запуск v2 (YOLOv8 + DeepSort)
python -m src.test.computer_vision_test_v2
```

## 📈 Вывод (Comparison)

**Версия 2 является существенно более совершенной по следующим причинам:**
1.  **Наличие трекинга**: DeepSort позволяет идентифицировать конкретный автомобиль на протяжении всего видео, а не просто детектировать его как "какой-то объект" в каждом кадре.
2.  **Скорость и точность**: YOLOv8n (nano) значительно быстрее устаревшей версии YOLOv3 и показывает лучшие результаты на детекции мелких объектов.
3.  **Специализация**: v2 настроена на фильтрацию только транспортных средств, что критично для задач UrbanFlow.

> [!TIP]
> Для продакшн-использования рекомендуется использовать Версию 2, так как она обеспечивает базу для подсчета уникальных транспортных средств и анализа траекторий.
